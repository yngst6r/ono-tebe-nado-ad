# Проект «Оно тебе надо»

[![Tests](https://github.com/yngst6r/ono-tebe-nado-ad/actions/workflows/tests.yml/badge.svg)](https://github.com/yngst6r/ono-tebe-nado-ad/actions/workflows/tests.yml)

Одностраничный сайт аукциона вещей, в которые никто не верил. Проект выполнен
по макету Яндекс Практикума с использованием семантической HTML-разметки,
Grid Layout, Flexbox и переиспользуемых CSS-компонентов.
